# QL-kho — MVP Spec

## Mục tiêu
Ứng dụng Android quản lý kho theo Material 3 + Glass/Blur, kiến trúc offline-first và backend dùng chung với Web.

## MVP đã dựng
- Dashboard.
- Danh sách sản phẩm.
- Tìm kiếm không phân biệt hoa/thường.
- Thêm nhanh sản phẩm tối thiểu bằng tên.
- Nhánh Cái mặc định.
- Khung đơn hàng, báo cáo, thông báo.
- GitHub Actions build debug APK.

## Bước backend tiếp theo
Firebase Authentication (Google), Firestore dùng chung Android/Web, Security Rules theo warehouse/member/permission, local Room + sync queue, WorkManager.

## Quy tắc nghiệp vụ cần giữ
- Dữ liệu có giao dịch không xóa hoàn toàn.
- Nhập nhân viên chờ duyệt; tự duyệt sau 10 phút theo thời điểm tạo thiết bị.
- Xuất mặc định FIFO.
- Tồn âm được phép và tách lợi nhuận thực tế/tham khảo.
- Lịch sử nghiệp vụ bảo toàn.
